# MentorSelectField 实现与使用文档

两个组件功能等价，均提供"选择导师"的完整表单交互（弹窗搜索、行单选、详情回填、字段同步），差异在于 **字段绑定方式**。

---

## 架构对比

### v1：隐藏 Input（MentorSelectField）

```text
Form.Item (无 name, label + 按钮)        ← 外层只负责外观
├── Table (展示已选导师)                   ← 只读视图
└── Form.Item (name, noStyle)             ← 内层负责字段绑定
    └── <Input style={{ display: 'none' }} />  ← 隐藏 Input 承接 value/onChange
```

- **值读取**：`Form.useWatch(name, form)` 订阅字段值
- **值写入**：`form.setFieldValue(name, id)` 手动更新
- **清空**：`form.setFieldValue(name, undefined)`
- **校验**：内层 `noStyle` Form.Item 持有 `rules`，静默校验后由外层展示错误

### v2：受控组件（MentorSelectField2）

```text
Form.Item (name, label + 按钮, rules)     ← 单层，同时负责外观和字段绑定
└── MentorFieldControl                    ← 受控子组件
    ├── Table (展示已选导师)
    └── MentorSelectModal (选择弹窗)
```

- **值读取**：`value` prop（Form.Item 通过 cloneElement 注入）
- **值写入**：`onChange?.(id)`（antd 自动更新字段值 + 触发校验）
- **清空**：`onChange?.(undefined)`
- **校验**：Form.Item 自身持有 `rules`，与 antd 原生控件一致

---

## 核心原理：antd Form.Item 的 value/onChange 协议

当 `Form.Item` 携带 `name` 属性时，会对**唯一子元素**执行 `React.cloneElement`，注入以下属性：

<table>
  <thead>
    <tr>
      <th>注入属性</th>
      <th>作用</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>value</code></td>
      <td>当前字段值，随表单状态自动更新</td>
    </tr>
    <tr>
      <td><code>onChange</code></td>
      <td>值变更回调，调用后 antd 自动更新字段值并触发校验</td>
    </tr>
    <tr>
      <td><code>id</code></td>
      <td>字段唯一标识</td>
    </tr>
    <tr>
      <td><code>onBlur</code></td>
      <td>失焦回调（默认 validateTrigger 之一）</td>
    </tr>
  </tbody>
</table>

这与 antd 内置的 `Select`、`DatePicker`、`Switch` 的机制完全一致——子组件只需声明 `value` 和 `onChange` 即可成为受控表单控件。

### getValueFromEvent

antd 默认通过 `getValueFromEvent` 从 `onChange` 参数中提取值：

```ts
function defaultGetValueFromEvent(valueProp, ...args) {
  const arg = args[0]
  if (arg?.target) {
    return arg.target[valueProp]  // 是事件对象 → 取 e.target.value
  }
  return arg  // 不是事件 → 直接使用
}
```

因此 v2 中 `onChange?.(mentor.id)` 会直接将 `mentor.id` 写入字段值，无需包装成事件对象。

## 使用方式

两个组件对外 API 完全一致，使用方可任选：

```tsx
import { MentorSelectField } from '@workspace/ui'       // v1
import { MentorSelectField2 } from '@workspace/ui'      // v2

<Form form={form}>
  <MentorSelectField name="mentorId" label="指导导师" />
</Form>

<Form form={form}>
  <MentorSelectField2 name="mentorId" label="指导导师" />
</Form>
```

提交时获取值的方式也相同：

```tsx
const values = form.getFieldsValue()
console.log(values.mentorId)  // "U00003"
```
